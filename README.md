## Descripción del proyecto
saludOax es una plataforma de gestión clínica pensada para escalar hacia 
un sistema integral de administración de consultorios (historial clínico, 
facturación, telemedicina, entre otros módulos futuros). En esta primera 
fase, el equipo enfoca el desarrollo en resolver el problema más crítico 
del proceso de atención: la falta de un tiempo estimado de consulta, que 
genera incertidumbre en los pacientes y los obliga a permanecer en sala de 
espera sin poder ausentarse. Mediante datos de salud recabados al llegar 
el paciente y un servicio de IA, el sistema calcula tiempo estimado y 
gravedad por consulta, dando contexto al médico y visibilidad real de 
espera a los pacientes en fila. La arquitectura modular del sistema 
permite incorporar nuevas funcionalidades sin reestructurar el núcleo base.
